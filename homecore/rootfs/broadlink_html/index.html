Captura de Código IR - Broadlink RM

Esta ferramenta permite capturar e salvar códigos de controle remoto infravermelho (IR) em um arquivo CSV.

Como usar:

  1. Preencha Marca e Modelo (serão lembrados para a próxima captura).
  2. Digite o nome do Botão que deseja aprender.
  3. Clique em Iniciar Captura de Código e aponte o controle para o Broadlink.
  4. O resultado mostrará os códigos e confirmará o salvamento na planilha CSV.
  5. Os códigos serão adicionados ao arquivo codigos_ir.csv.
