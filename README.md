# HomeCore Add-ons para Home Assistant

Repositório de add-ons oficiais do HomeCore pra instalação direta no Home Assistant OS / Supervised.

## Como instalar

1. No Home Assistant, vá em **Settings → Add-ons → Add-on Store**.
2. Clique no menu **⋮** (canto superior direito) → **Repositories**.
3. Cole a URL deste repositório:
   ```
   https://github.com/willianmagna/HomeCore-AddOn
   ```
4. Clique em **Add** e feche a janela.
5. O add-on **HomeCore** vai aparecer na loja — clique **Install**.

## Add-ons disponíveis

| Add-on | Descrição |
|--------|-----------|
| [HomeCore](./homecore) | Marketplace de automação residencial — Sonoff/Tuya Wi-Fi, Zigbee e IR Broadlink integrados via MQTT Discovery. |
